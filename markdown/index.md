# PixelIndieDev
> Null stack developer.

PixelIndieDev (also sometimes known as Pixel) is an independent game developer, open-source contributor, and mod creator specializing in quality-of-life improvements, gameplay tweaks, non-serious additions and developer utilities. Sometimes he also creates software/mods that already exist, but do not have the code public, are by him considered as a possible security risk or the exiting project does not have the wanted features and experience.

## Website appearance (`pixelindiedev.github.io`)
His site features a bright friendly look with his Piggy mascot visible and falling hearts in the background. The background is #bcf9f8 and the hearts are slightly transparent variants of white. Hovering over specific buttons causes the background and/or the mascot to visible change.
The eyes of the Piggy follow the cursor on desktop devices. It also makes facial expression as you navigate the site.
